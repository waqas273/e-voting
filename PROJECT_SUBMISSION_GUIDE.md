# 🚀 Developer Project Submission Guide
### Portfolio Project Publishing Requirements & Specification Checklist

Use this guide to collect all necessary details and media assets before publishing a project to the portfolio.

---

## 📋 Required Information Checklist

### 1. Basic Project Details (`General Info`)

| Field Name | Type | Description / Guidance | Example |
| :--- | :--- | :--- | :--- |
| **Project Title** | String | The official title or name of the application. | `Quantum Cyber Dashboard` |
| **Category** | Dropdown | Select either `Full-Stack` or `Frontend`. | `Full-Stack` |
| **Code Tab Filename** | String | Visual filename shown on the project code header. | `Dashboard.tsx` or `App.jsx` |
| **Short Description** | Text (Short) | A concise 2-3 sentence overview shown on the main portfolio project card. | `High-performance developer tracking matrix linking Firestore telemetry streams with WebSockets for visual analytics.` |
| **Live Demo URL** | URL Link | Public live URL where the application can be tested. | `https://quantum-cyber.vercel.app` |
| **GitHub Repository URL** | URL Link *(Optional)* | Link to the GitHub code repository (if open-source). | `https://github.com/waqas273/quantum-cyber` |

---

### 2. Technical Specifications (`Tech Specs`)

| Field Name | Type | Description / Guidance | Example |
| :--- | :--- | :--- | :--- |
| **Tech Stack Array** | Comma-Separated List | Technologies, frameworks, databases, and tools used. | `React, Firebase, Tailwind, Node.js, WebSockets` |
| **Long Description** | Text (Detailed) | Comprehensive executive summary & system architecture overview for the dedicated Project Specifications view. | `An enterprise-grade developer tracking matrix built to aggregate live server metrics, database read/write throughput, and WebSocket diagnostics into a unified HUD interface...` |
| **Core Capabilities** | List (One per line) | Key technical features and highlights of the project. | • `Real-time Firestore telemetry streams`<br>• `Custom SVG graph widgets`<br>• `OAuth 2.0 multi-tenant authentication`<br>• `Cloudinary CDN media pipeline` |

---

### 3. Media Assets & Multi-Page Gallery (`Media Gallery`)

To enable the **Auto-Sliding Image Carousel** and **Per-Page Caption Explanations**, provide the following media assets:

#### A. Main Cover Image
- **Format:** PNG, JPG, WEBP, or GIF (high resolution).
- **Aspect Ratio:** 16:9 widescreen landscape recommended (e.g. 1920x1080 or 1280x720).
- **Purpose:** Displayed on the main portfolio project card and admin registry preview.

#### B. Page Screenshots & Explanations (Multiple Slides)
Provide **2 to 5 high-quality screenshots** representing different sections/pages of the application, along with a custom caption for each slide:

1. **Screenshot #1 (Main Overview Page):**
   - **Image File:** `slide1_dashboard.png`
   - **Page Explanation:** `Main Telemetry Overview - Displays live client node metrics, bandwidth consumption, and server CPU load graphs.`

2. **Screenshot #2 (Admin Console / Control Deck):**
   - **Image File:** `slide2_analytics.png`
   - **Page Explanation:** `Analytics Control Console - Detailed query inspector, WebSocket channel activity logs, and system health status.`

3. **Screenshot #3 (Security & User Auth):**
   - **Image File:** `slide3_security.png`
   - **Page Explanation:** `Security Audit & Auth Logs - Audit trails monitoring IP access logs, JWT token validation, and 2FA authentication states.`

## ⚡ Roman Urdu Guide Summary for Quick Reference

 developers ko ye details fill karke deni hongi project portfolio par publish karwane ke liye:

1. **Project Title**: Project ka naam (e.g., `E-Commerce Storefront`).
2. **Category**: `Full-Stack` ya `Frontend`.
3. **Filename**: Frontend tab par display hone wala name (e.g., `App.jsx` ya `Store.tsx`).
4. **Short Summary**: Project ki 2-3 lines ki brief summary jo project card par show hogi.
5. **Detailed Overview**: Project ki complete explanation jo full-page project specs view mien show hogi.
6. **Tech Stack**: Used technologies (e.g., `React, Node.js, MongoDB, Tailwind`).
7. **Key Features**: Main capabilities ki bullet points list.
8. **Main Cover Image**: High quality main cover picture.
9. **Page Screenshots & Explanations**: 2-5 pages/sections ki screenshots aur har picture ki alag detail/caption text jo auto-sliding carousel mien show hogi.
10. **Live Link & GitHub**: Working Live Demo URL + optional GitHub code link.
